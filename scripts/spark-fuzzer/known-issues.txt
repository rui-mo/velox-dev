# Functions that 'spark_fuzzer.py run' skips because of known, unfixed issues.
# One function name or signature without commas per line. '#' starts a
# comment. Remove the line in the commit that fixes the issue.

# Velox evaluates the initial state for all rows, and fails on errors in rows
# whose array is null. Spark returns null without evaluating it.
aggregate
# Velox limits the number of elements to 10000 by
# 'max_elements_size_in_repeat_and_sequence', while Spark doesn't.
array_repeat
# Spark treats the delimiters as regular expressions.
str_to_map
# Velox uses glibc's math functions, while Java's Math.cbrt and Math.atan2 use
# the fdlibm algorithms. Their results differ in the last bit for 55% of random
# inputs of cbrt and 14% of atan2, which changes results of discontinuous
# functions, e.g. width_bucket, remainder and casts to strings.
atan2
cbrt
